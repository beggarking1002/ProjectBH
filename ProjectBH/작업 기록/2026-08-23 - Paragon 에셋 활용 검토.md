# 2026-08-23 - Paragon 에셋 활용 검토

## 목적

무료 Paragon 영웅 에셋을 ProjectBH의 네 플레이어 클래스에 사용하는 방안을 검토한다.

## Codex 변경 사항

- Paragon을 공용 모험가 에셋안과 Mixamo 분리 캐릭터안보다 우선 검토할 강력한 후보로 정리했다.
- 탱커·전사·도적·마법사의 Paragon 후보 조합을 작성했다.
- 서로 다른 Skeleton/AnimBP를 유지하되, C++ 전투 시스템과 캐릭터별 애니메이션 데이터를 분리하는 구조를 제안했다.
- Paragon 상표 및 원래 영웅 명칭을 ProjectBH에 사용하지 않는 원칙을 기록했다.

## 사용자 에디터 작업

1. Fab에서 전사 후보 하나를 Library에 추가한다.
2. ProjectBH에 전사 후보 팩만 먼저 추가한다.
3. 메시, AnimBP, 공격, 피격, 사망, 소켓을 테스트한다.

## 검증

- Epic은 Paragon 콘텐츠에 다수의 캐릭터, Animation Blueprint, 스킨, VFX, 애니메이션을 포함한다고 안내한다.
- Fab의 Greystone 페이지는 해당 팩이 무료이며 UE 프로젝트에서 사용할 수 있다고 안내하고, Paragon 상표를 게임 이름·홍보에 사용할 수 없다고 명시한다.

## 추가 조사: 석궁 영웅

- 현재 확인된 Paragon 영웅 중 석궁 주무기 캐릭터는 없다.
- `Sparrow`는 활 전문 궁수로, 활 기반 원거리 전투의 참고 후보가 될 수 있다.
- ProjectBH에서는 석궁을 공용 보조장비로 별도 구현한다.
