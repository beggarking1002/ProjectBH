# 2026-08-27 - 군중 몬스터 구현 순서 확정

## 목적

NavMesh 중심의 군중 몬스터 설계를 실제 구현 가능한 수직 슬라이스 순서로 고정한다.

## 결정

첫 구현은 전역 길찾기를 다시 만드는 일이 아니라, **단일 적 NavMesh 추적**이다.

이후의 고정 순서는 다음과 같다.

```text
단일 적 NavMesh 추적
  → 단일 적 공격 루프
  → Combat Engagement Slot
  → Detour Crowd 군중 검증
  → 포트폴리오 계측/비교
  → 벽면 Traversal
```

## 근거

- 현재 `ABHEnemy`와 Enemy AnimInstance는 준비됐지만 실제 AI `MoveTo` 연결은 아직 검증하지 않았다.
- 전투 슬롯, 군중 회피, 벽면 등반은 모두 "적이 지정된 NavMesh 목적지까지 안정적으로 이동한다"는 전제 위에 있다.
- 따라서 단일 적 추적을 통과시켜야 이후 문제를 경로 연결 문제와 고유 시스템 설계 문제로 분리할 수 있다.

## Codex 다음 구현 범위

- `ABHCrowdEnemyAIController` 추가
- 서버 권한 플레이어 타깃 획득
- NavMesh의 `MoveToActor` 기반 최소 추적
- 실제 AI 시작 시 AnimBP 확인용 `bWalkLeftForAnimationPreview`를 끄는 흐름 안내

## 사용자 에디터 작업

1. 테스트 맵의 전투 구역에 `NavMeshBoundsVolume`을 배치한다.
2. `BP_Enemy_Base`를 맵에 한 마리 배치하고 Enemy AnimBP를 연결한다.
3. 해당 Enemy의 `bWalkLeftForAnimationPreview`를 끈다.
4. `P` 키로 NavMesh가 적과 플레이어 사이에 생성됐는지 확인한다.

## 완료 조건

서버와 클라이언트에서 적 한 마리가 NavMesh 위를 따라 플레이어의 정지 거리까지 이동하고, Enemy AnimBP의 이동 Blend Space가 재생된다.
