# 2026-08-23 - 언리얼 에셋 마이그레이션 가이드 작성

## 목적

다른 Unreal Engine 프로젝트의 캐릭터·애니메이션·머티리얼 등 에셋을 ProjectBH로 안전하게 가져오는 절차를 정리한다.

## Codex 변경 사항

- Unreal Editor의 `Asset Actions → Migrate`를 사용하는 표준 절차를 작성했다.
- 캐릭터 이관 시 필요한 의존성과 ProjectBH 내 정리·검증 절차를 작성했다.
- 반복 절차 문서는 `개발 가이드/`에 분리하는 문서 구조를 협업 원칙에 추가했다.

## 사용자 에디터 작업

- 다른 프로젝트에서 캐릭터 에셋을 옮길 때 개발 가이드의 Migrate 절차를 따른다.

## 검증

- Epic Games 공식 문서에서 Migrate 기능이 참조 의존성을 함께 복사하고, 대상 프로젝트의 `Content` 폴더를 선택해야 함을 확인했다.
