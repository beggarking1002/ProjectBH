# 2026-08-23 - 공용 캐릭터 에셋 색상 설정 안내

## 목적

선택한 Polyart 모듈형 캐릭터 에셋의 머리색 및 의상 색상 설정 방법을 정리한다.

## Codex 변경 사항

- 프로젝트에 `Polyart/ModularStylizedChars` 에셋과 색상 커스터마이즈용 레벨, 머티리얼 인스턴스, 색상 데이터 에셋이 이미 존재함을 확인했다.
- 전사 색상 초안을 적갈색·어두운 가죽·소량의 금색 포인트로 제안했다.
- 원본 에셋은 보존하고, 프로젝트 전용 복제 머티리얼 인스턴스로 클래스 색상을 고정하는 방침을 작성했다.

## 사용자 에디터 작업

1. `Content/Polyart/ModularStylizedChars/Levels/ColorCustomizationLevel`을 열고 Play를 실행해 제공 커스터마이즈 UI를 확인한다.
2. `BP_GarretSimple`을 기준 캐릭터로 열어 현재 사용하는 메시와 머티리얼 슬롯을 확인한다.
3. 활성 머티리얼 인스턴스를 `Content/ProjectBH/Characters/Common/Materials/`로 복제한다.
4. 복제한 인스턴스에서 의상·가죽·금속·머리카락 색상 파라미터를 전사 색상 초안에 맞게 조절한다.
5. 변경한 인스턴스를 전사 블루프린트의 해당 머티리얼 슬롯에 지정한다.

## 검증

- 에셋에는 `ColorCustomizationLevel`, `BP_GarretSimple`, 색상 마스크, `MI_Male*` 머티리얼 인스턴스, 색상 데이터 에셋이 포함되어 있다.
- 실제로 노출되는 파라미터의 이름과 커스터마이즈 UI의 저장 동작은 에디터에서 확인해야 한다.
