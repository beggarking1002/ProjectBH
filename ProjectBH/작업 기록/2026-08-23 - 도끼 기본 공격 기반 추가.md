# 2026-08-23 - 도끼 기본 공격 기반 추가

## 목표

- 첫 도끼 기본 공격을 리슨 서버 멀티플레이 기준으로 구현한다.
- 애니메이션 타격 프레임과 실제 피해 판정을 분리한다.

## C++ 구현

- `InputTag.BasicAttack` 네이티브 게임플레이 태그를 추가했다.
- `ABHHeroCharacter`에 기본 공격 흐름을 추가했다.
  - 클라이언트 입력은 서버 RPC로 전달된다.
  - 서버가 쿨다운을 검사한 뒤 모든 클라이언트에 공격 몽타주 재생을 알린다.
  - `BH Basic Attack Hit` 애님 노티파이가 있는 프레임에서만 서버가 구형 Sweep 판정을 한다.
  - 유효 타깃의 Ability System Component에는 `BasicAttackDamageEffect`를 적용한다.
- BP에서 조절할 수 있는 값:
  - `BasicAttackMontage`
  - `BasicAttackDamageEffect`
  - `BasicAttackCooldown` (기본 0.8초)
  - `BasicAttackRange` (기본 175)
  - `BasicAttackRadius` (기본 75)

## 에디터 설정 순서

### 1. 입력 에셋

1. `Content/PlayerCharacter/Input/Actions`에 `IA_BasicAttack`을 만든다.
2. Value Type은 `Boolean`으로 둔다.
3. `IMC_Default`에 `IA_BasicAttack`을 추가하고 마우스 왼쪽 버튼을 지정한다.
4. `DA_InputConfig`의 `NativeInputActions` 배열에 항목을 추가한다.
   - Input Tag: `InputTag.BasicAttack`
   - Input Action: `IA_BasicAttack`

### 2. 공격 몽타주

1. `Hero_Axe_LightAttack_1`에서 우클릭해 `Create > Create AnimMontage`를 선택한다.
2. 몽타주 이름은 `AM_Hero_Axe_LightAttack_1`로 한다.
3. 몽타주 노티파이 트랙에서 도끼가 목표를 지나가는 프레임에 `Add Notify > BH Basic Attack Hit`을 하나 둔다.

### 3. 피해 Gameplay Effect

1. `Content/Combat/Effects` 폴더를 만든다.
2. `Gameplay Effect` 부모로 `GE_BasicAttackDamage`를 만든다.
3. Duration Policy는 `Instant`로 한다.
4. Modifiers에 다음 한 줄을 넣는다.
   - Attribute: `BHAttributeSet.Health`
   - Modifier Op: `Add`
   - Magnitude: `-20`

### 4. 영웅 BP 연결

`BP_Hero`의 Class Defaults > `Combat > Basic Attack`에 다음을 지정한다.

- Basic Attack Montage: `AM_Hero_Axe_LightAttack_1`
- Basic Attack Damage Effect: `GE_BasicAttackDamage`

## 검증 기준

- 리슨 서버 호스트와 클라이언트 모두 서로의 공격 몽타주를 본다.
- 몽타주 내 `BH Basic Attack Hit` 프레임에만 더미가 피해를 받는다.
- 체력 변경은 서버에서 발생하고 GAS 속성 복제로 동기화된다.
