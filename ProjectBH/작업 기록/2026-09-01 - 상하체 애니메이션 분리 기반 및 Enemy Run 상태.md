# 상하체 애니메이션 분리 기반 및 Enemy Run 상태

## 목표

- Player가 이동 공격 중 하체 Locomotion을 유지할 수 있는 공통 Slot 정책을 확립한다.
- Enemy도 같은 UpperBody/FullBody 정책을 사용할 수 있게 한다.
- Enemy가 `Chasing` 상태로 실제 이동할 때 걷기가 아니라 Run State를 사용하게 한다.

## C++ 변경

`BHEnemyAnimInstance`에 다음 BlueprintReadOnly 값을 추가했다.

- `bIsChasing`: `CombatState == Chasing`
- `bShouldUseRunLocomotion`: `bIsChasing && bShouldMove`

`bShouldMove`의 기존 `10 cm/s` 진입, `5 cm/s` 이탈 히스테리시스는 유지한다. 따라서 경로 갱신 중 가속도가 잠깐 0이 되더라도 Run/Idle이 즉시 깜빡이지 않는다. 기존 `bHasAcceleration` 호환 출력도 유지한다.

## 애니메이션 정책

- 공통 Slot: `CombatGroup.UpperBody`, `CombatGroup.FullBody`
- Player 이동 허용 기본 공격: 우선 UpperBody
- Guardian 현재 공격·피격·사망: FullBody
- Guardian Chasing 이동: `bShouldUseRunLocomotion`으로 Run 선택

AnimBP와 Montage는 바이너리 `.uasset`이므로 [[상하체 애니메이션 분리 및 Enemy Run 연결 절차]]에 따라 사용자가 Unreal Editor에서 연결한다.

- `ProjectBHEditor Win64 Development`에서 UHT, C++ 컴파일, DLL 링크 성공.
- AnimGraph 합성 결과와 실제 Run Animation 선택은 PIE 검증 대기.
