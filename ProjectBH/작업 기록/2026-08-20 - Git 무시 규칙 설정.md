# 2026-08-20 - Git 무시 규칙 설정

## 목적

Unreal Engine 5 C++ 프로젝트에서 생성되는 대용량·로컬 전용 파일이 버전 관리에 포함되지 않도록 Git 무시 규칙을 추가한다.

## Codex 변경 사항

- 저장소 루트에 `.gitignore`를 추가했다.
- Unreal Engine 생성 산출물(`Binaries`, `DerivedDataCache`, `Intermediate`, `Saved`)을 제외했다.
- 프로젝트 로컬 플러그인 폴더(`Plugins/`)를 제외했다.
- Unreal Engine이 IDE 연동 시 재생성하는 솔루션 및 프로젝트 파일을 제외했다.
- Visual Studio와 Rider/IntelliJ의 로컬 설정 및 디버그·빌드 산출물을 제외했다.
- 옵시디언 문서는 추적하되, 개인 작업공간 상태와 휴지통만 제외했다.

## 사용자 에디터 작업

없음.

## 검증

- 프로젝트 루트에 기존 `.gitignore`가 없음을 확인했다.
- 현재 폴더는 아직 Git 저장소로 초기화되지 않아 `git status`는 실행할 수 없었다.

## 관련 파일

- `/.gitignore`
