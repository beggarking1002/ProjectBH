# 런타임 디버그 표시 토글 구현

## 작업 목적

PIE 또는 게임 실행 중 화면을 채우는 ProjectBH 디버그 표시를 에디터를 종료하지 않고 전체 또는 종류별로 켜고 끌 수 있게 한다.

## 기존 기능

다음 인스턴스별 설정은 이미 있었다.

- Enemy AI Controller: `Draw Crowd Debug`
- Hero의 Combat Engagement Slot Component: `Draw Debug Slots`
- Enemy Pool Manager: `Draw Pool Debug`

기존 설정은 Class Defaults나 Level Instance에서 정적으로 바꾸는 방식이며, 실행 중 전체 표시를 한 번에 전환하는 공용 명령은 없었다.

## 구현 결과

- `BHDebugDraw` 공용 런타임 스위치를 추가했다.
- Master, Crowd, Slots, Pool 네 Console Variable을 추가했다.
- `bh.Debug.Toggle` 명령으로 Master를 즉시 전환한다.
- 토글 결과를 로그와 2초짜리 화면 메시지로 알린다.
- 기존 인스턴스별 bool과 런타임 Console Variable을 AND 조건으로 결합했다. 인스턴스 bool이 꺼진 표시는 런타임 명령으로 강제로 켤 수 없으며, 런타임 스위치는 기존에 허용된 표시를 일시적으로 끄고 다시 허용하는 역할을 한다.
- 기본값은 모두 `1`이므로 기존 표시 동작은 바뀌지 않는다.

## 사용 명령

```text
bh.Debug.Toggle
bh.Debug.Enabled 0
bh.Debug.Enabled 1
bh.Debug.Crowd 0
bh.Debug.Crowd 1
bh.Debug.Slots 0
bh.Debug.Slots 1
bh.Debug.Pool 0
bh.Debug.Pool 1
```

`bh.Debug.Toggle`만 현재 Master 상태를 반전한다. Crowd·Slots·Pool은 각각 `0` 또는 `1`을 명시해서 설정한다.

## 검증

- Unreal Engine 5.7 `ProjectBHEditor Win64 Development` 빌드 성공.
- Master와 종류별 CVar의 On/Off, 인스턴스 bool과의 조합, 기본값에서 기존 표시 유지, 토글 로그·2초 화면 메시지와 화면 소멸은 PIE에서 확인해야 한다.
