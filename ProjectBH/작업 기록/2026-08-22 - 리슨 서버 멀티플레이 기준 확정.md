# 2026-08-22 - 리슨 서버 멀티플레이 기준 확정

## 목적

ProjectBH의 이후 구현 판단에 사용할 네트워크 모델과 권한 원칙을 확정한다.

## Codex 변경 사항

- 프로젝트의 네트워크 모델을 리슨 서버 기반 온라인 코옵으로 명시했다.
- 첫 검증 목표를 호스트 1명과 클라이언트 1명의 2인 세션으로 고정했다.
- 체력, 피해, AI, 스폰, 웨이브, 승패를 서버 권한 게임플레이 결과로 분류했다.
- 클라이언트는 입력 의도를 보내고, 연출은 서버가 확정해 복제한 결과를 바탕으로 재생하는 원칙을 기록했다.

## 사용자 에디터 작업

- PIE 멀티플레이 테스트는 Listen Server 1명과 Client 1명 설정으로 진행한다.

## 검증

- 현재 `ABHBaseCharacter`는 이동 복제와 Ability System Component 복제 설정을 갖고 있다.
- 실제 피해·공격 복제는 이후 전투 수직 슬라이스에서 구현·검증한다.
