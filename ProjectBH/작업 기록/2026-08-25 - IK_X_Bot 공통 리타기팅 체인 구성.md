# IK_X_Bot 공통 리타기팅 체인 구성

- 작업 일자: 2026-08-25
- 대상 자산: `/Game/Assets/MixamoAnim/IK_X_Bot`
- 기준 문서: `개발 가이드/IK Rig 공통 리타기팅 체인 표준.md`

## 반영 내용

`IK_X_Bot`에 아래 공통 체인 이름을 직접 구성했다.

- 몸통/사지: `Spine`, `LeftArm`, `RightArm`, `LeftLeg`, `RightLeg`, `Neck`, `Head`
- 손가락: `LeftThumb`, `LeftIndex`, `LeftMiddle`, `LeftRing`, `LeftPinky`, `RightThumb`, `RightIndex`, `RightMiddle`, `RightRing`, `RightPinky`

체인 이름은 다른 IK Rig 및 향후 IK Retargeter와 같은 이름으로 매핑되도록 공통 표준을 그대로 사용했다. IK Goal은 추가하지 않았다.

## X Bot 스켈레톤 대응

X Bot에는 Paragon의 `pelvis` 본이 없으므로, 이 자산의 Retarget Root는 실제 골반 루트인 `Hips`로 지정했다. 이는 Mixamo 본 구조에 따른 자산별 본 대응이며, 공통 체인 명세 자체를 변경한 것은 아니다.

- Spine: `Spine` → `Spine2`
- Arms: `LeftShoulder`/`RightShoulder` → 각 `Hand`
- Legs: `LeftUpLeg`/`RightUpLeg` → 각 `Foot`
- Neck/Head: 각 단일 본 체인
- Fingers: 각 손가락의 `1` → `3` 본

## 검증

UE 5.7 헤드리스 에디터로 자산을 다시 불러와 Retarget Root 및 17개 체인의 시작/종료 본이 모두 저장된 구성과 일치함을 확인했다.

## 후속 이슈: T/A 기준 포즈 차이

X Bot은 T 포즈, Greystone은 A 포즈이므로 리타게팅 후 팔·어깨가 어긋날 수 있다. 이는 체인 명세를 바꿀 문제가 아니라, IK Retargeter에서 Greystone Target Retarget Pose를 T 포즈에 맞춰 보정할 문제다. 상세 절차는 `개발 가이드/IK 리타게팅 포즈 보정 가이드.md`를 따른다.
