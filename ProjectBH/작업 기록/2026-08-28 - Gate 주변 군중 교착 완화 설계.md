# 2026-08-28 - Gate 주변 군중 교착 완화 설계

> Gate 기능은 [[2026-08-28 - Attack Approach Gate 롤백]]에서 제거했다. 이 문서의 Crowd Following 기본값 분석과 강화 설정 제안만 후속 작업 근거로 유지한다.

## 목적

Attack Approach Gate 도입 후 Gate Ring 주변에서 Enemy가 서로 마주치거나 밀착해 끼는 현상의 원인을 확인하고 완화 방향을 정리한다.

## 확인된 원인

### Detour Crowd 기본 설정

UE 5.7 로컬 엔진 소스의 `UCrowdFollowingComponent` 기본값은 다음과 같다.

- Obstacle Avoidance: 활성화
- Separation: 비활성화
- Separation Weight: 2.0
- Avoidance Quality: Low
- Collision Query Range: 400 cm
- Anticipate Turns: 비활성화

현재 `ABHCrowdEnemyAIController`는 이 기본값을 별도로 조정하지 않는다. 따라서 경로 회피는 하지만 Agent 사이의 능동적인 간격 확보가 약하다.

### Gate와 Wait의 교통 혼합

- `AttackApproachGateRadius = 0`은 Gate 반경으로 Wait Ring Radius 300 cm를 사용한다.
- 움직이는 Attack Enemy와 정지 목표에 도착한 Wait Enemy가 같은 Ring을 사용한다.
- 8개 Wait Slot 사이로 Capsule 반지름 약 42 cm의 Enemy가 통과할 수는 있지만 Detour의 회피 여유까지 포함하면 병목이 좁다.

### 양방향 Orbit

- 현재 `OrbitToGate`는 목표 Gate까지 절대 각도가 짧은 방향을 선택한다.
- 여러 Attack Enemy가 같은 Ring에서 시계·반시계 방향으로 동시에 움직여 정면으로 마주칠 수 있다.
- Detour가 좁은 Ring에서 서로 양보하려다 좌우 속도를 반복 변경하면 버벅임이 발생한다.

## 권장 변경 묶음

### 1. Crowd Following 명시 설정

첫 검증값은 다음과 같이 둔다.

| 항목 | 값 |
| --- | ---: |
| Separation | On |
| Separation Weight | 2.0 |
| Avoidance Quality | High |
| Anticipate Turns | On |
| Collision Query Range | 500 cm |
| Avoidance Range Multiplier | 1.2 |

Separation Weight를 처음부터 과도하게 올리지 않는다. 높은 Separation은 슬롯 도착 후 미세 진동과 목표점 이탈을 만들 수 있으므로 2.0부터 검증한다.

### 2. Attack Approach Ring 분리

- Attack Approach Gate Radius를 400 cm로 둔다.
- Wait Ring 300 cm와 Holding Ring 500 cm 사이에 움직이는 Attack 전용 교통 Ring을 만든다.
- Attack Enemy는 400 cm Ring에서 각도를 맞춘 뒤 300 cm Wait Ring의 빈 각도 사이로 진입한다.

### 3. Orbit 일방통행

- 모든 Attack `OrbitToGate` 이동은 한 방향으로 통일한다.
- 첫 기준은 시계 방향으로 둔다.
- 최단 방향보다 이동 거리가 길어질 수 있지만 정면 충돌과 상호 양보 교착을 줄인다.
- 같은 Ring의 Enemy는 추월보다 줄서기를 선택하게 된다.

## 후속 조정 순서

1. 위 세 변경을 함께 적용한다.
2. Gate Ring에서 마주침이 사라지는지 확인한다.
3. Ingress 시 Wait 두 명 사이가 여전히 좁을 때만 Wait Ring Radius를 325 cm로 늘린다.
4. 325 cm에서도 좁으면 350 cm를 비교한다.
5. 슬롯 도착 후 Enemy가 흔들리면 Separation Weight를 낮추거나 Slot 도착 상태에서 Crowd Simulation 감속을 별도로 검토한다.

## 유지할 원칙

- Capsule Collision은 유지한다.
- RVO Avoidance는 Detour Crowd와 동시에 사용하지 않는다.
- Stuck Timeout 단축으로 해결하지 않는다.
- Enemy 관통이나 순간이동으로 교착을 숨기지 않는다.
