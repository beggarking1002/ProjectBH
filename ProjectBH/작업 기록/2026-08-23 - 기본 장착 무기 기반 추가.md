# 2026-08-23 - 기본 장착 무기 기반 추가

## 목적

전사가 서버 권한으로 기본 무기를 장착하고, 리슨 서버와 모든 클라이언트에 동일한 장착 상태가 보이는 기반을 만든다.

## Codex 변경 사항

- 복제되는 장착 무기 액터 `ABHWeapon`을 추가했다.
- 무기 액터는 `WeaponMesh` Static Mesh Component를 루트로 사용하며, 장착 상태에서는 충돌을 사용하지 않는다.
- `ABHHeroCharacter`에 `StartingWeaponClass`와 복제되는 `EquippedWeapon`을 추가했다.
- 서버가 Hero를 Possess할 때 시작 무기를 Spawn하고, 캐릭터 메시의 `Weapon_R` 소켓에 부착하도록 구현했다.
- 소켓이 없거나 무기 생성에 실패한 경우 원인을 로그에 남긴다.

## 사용자 에디터 작업

1. `SK_CharM_Barbarous`의 `hand_r`에 `Weapon_R` 소켓을 추가하고 `SM_DefaultAxe`로 위치와 회전을 조정한다.
2. `ABHWeapon` 기반 `BP_DefaultAxe`를 만든 뒤 `WeaponMesh`에 `SM_DefaultAxe`를 지정한다.
3. `BP_BHHeroCharacter`의 `StartingWeaponClass`에 `BP_DefaultAxe`를 지정한다.
4. Listen Server 1명과 Client 1명 PIE에서 양쪽 캐릭터의 도끼가 서로에게 보이는지 확인한다.

## 검증

- `ProjectBHEditor Win64 Development` 전체 빌드가 `Result: Succeeded`로 완료됐다.
- 에디터 소켓과 블루프린트 에셋 지정은 아직 사용자가 수행해야 한다.
