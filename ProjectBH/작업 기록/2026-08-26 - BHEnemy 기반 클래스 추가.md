# BHEnemy 기반 클래스 추가

- 작업 일자: 2026-08-26
- 목적: 모든 전투 몬스터가 공유할 네트워크/GAS 기반과 군중 이동 기반을 마련한다.

## 추가·변경 파일

- `Source/ProjectBH/Enemies/BHEnemy.h`
- `Source/ProjectBH/Enemies/BHEnemy.cpp`
- `Source/ProjectBH/ProjectBH.Build.cs`

## 구현 내용

- `ABHEnemy`를 `ABHBaseCharacter` 상속의 `Abstract`, `Blueprintable` C++ 기반 클래스로 추가했다.
- 배치 또는 스폰된 Enemy가 자동으로 AI에 의해 점유되도록 `AutoPossessAI = PlacedInWorldOrSpawned`를 설정했다.
- 기본 AI Controller를 UE의 `ADetourCrowdAIController`로 지정했다.
  - NavMesh 경로 위에서 몬스터끼리의 근거리 회피를 제공한다.
  - RVO는 사용하지 않는다.
- `AIModule` 의존성을 추가했다.

이 클래스는 아직 공격·추적 행동을 실행하지 않는다. 이후 `CombatEngagementSlotComponent`와 구체 몬스터 AI가 플레이어가 아닌 예약된 Attack/Wait Slot 위치로 이동 명령을 내리게 한다.

## 검증

`ProjectBHEditor Win64 Development` 빌드 성공.

## 사용자 에디터 작업

1. 에디터를 다시 열거나 C++ 변경사항을 반영한다.
2. `All Classes`에서 `BHEnemy`를 부모로 하는 `BP_Enemy_Base` Blueprint를 만든다.
3. 아직은 전투/추적 로직이 없으므로, Mesh·Capsule·Animation Blueprint를 연결하는 공통 베이스로만 둔다.
4. 이후 `BP_Enemy_Grunt` 등 구체 몬스터 Blueprint가 이를 상속한다.

## 후속: Enemy Animation Instance 기반 추가

- `UBHEnemyAnimInstance`를 `UBHCharacterAnimInstance` 상속으로 추가했다.
- `GroundSpeed`, `Direction`, `bHasAcceleration`은 기존 공통 Character AnimInstance에서 그대로 받는다.
- Enemy 전용 AnimBP에서 사용할 `OwningEnemy` 참조를 제공한다.
- 추후 공격 슬롯 점유, 전투 상태, 경직, 사망 같은 적 전용 애니메이션 변수는 실제 적 AI 상태가 구현될 때 추가한다. 현재 존재하지 않는 게임 상태를 임의의 bool로 만들지 않는다.

### 검증 상태

- UnrealHeaderTool 검증은 성공했다.
- 외부 Editor 빌드는 실행 중인 Unreal Editor의 Live Coding 때문에 차단됐다. 에디터에서 `Ctrl+Alt+F11`로 Live Coding 컴파일을 실행하거나, 에디터를 종료한 뒤 일반 빌드를 실행해 최종 검증한다.

## 후속: Hero Relax 상태 제거

- `UBHHeroAnimInstance`에서 `bShouldEnterRelaxState`, `EnterRelaxStateThreshold`, `IdleElapsedTime`과 관련 업데이트 로직을 제거했다.
- Hero와 Enemy 모두 공통 이동 데이터만 `UBHCharacterAnimInstance`에서 받는다.
- 기존 Hero AnimBP가 제거된 `bShouldEnterRelaxState`를 Transition Rule에 사용하고 있었다면, 해당 Rule도 에디터에서 제거하거나 다른 조건으로 교체해야 한다.
