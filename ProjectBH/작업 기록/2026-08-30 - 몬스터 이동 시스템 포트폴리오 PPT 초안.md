# 몬스터 이동 시스템 포트폴리오 PPT 초안

## 작업 목적

지금까지 구현한 몬스터 이동 시스템을 시스템 기획·프로그래밍 포트폴리오에서 설명할 수 있도록 12장 분량의 PPT 초안으로 정리했다.

핵심 메시지는 다음과 같다.

> 길찾기는 언리얼 엔진에 맡기고, 몬스터 떼가 어디로 이동하고 어떤 순서로 자리를 차지하며 실패를 어떻게 복구할지는 직접 설계했다.

## 결과물

- PPTX: `ProjectBH/포트폴리오/ProjectBH_몬스터_이동_시스템_포트폴리오_초안.pptx`
- 슬라이드 수: 12장
- 화면 비율: 16:9
- 편집 방식: 텍스트와 도형이 PowerPoint에서 편집 가능한 형태

## 슬라이드 구성

1. 표지: `몬스터 떼, 어떻게 행동할 것인가?`
2. 문제 정의: MoveTo만으로는 집단 행동을 만들 수 없는 이유
3. 구조: NavMesh·Detour Crowd와 커스텀 Engagement System의 책임 분리
4. 핵심 흐름: Pursuit → Formation → Attack → Recovery
5. 자리 구조: Attack 5, Wait 8, Holding 16, Pending Queue
6. 공간 적응: Open·Corridor·Pocket 대형 비교
7. Corridor Queue: Side × Lane 독립 대기열과 양방향 전선
8. 승격과 복구: 도착·경로·혼잡·Sequence·Watchdog
9. 이동 품질: Engagement Anchor, 가속 이동, 재경로 제한, Player Focus
10. 생명주기: 시체 연출을 보존하는 Object Pool 정책
11. 구현 표면: 주요 C++ 클래스, Data Asset, 런타임 디버그 명령
12. 검증과 다음 단계: PIE 검증 축과 포트폴리오 증거 계획

## 표현 원칙

- 구현한 기능과 검증 완료 상태를 분리했다.
- 최신 양방향 Corridor와 Pocket 대형은 코드 구현 및 UE 5.7 에디터 빌드 성공으로 표기하고, 실제 플레이 품질은 PIE 검증이 필요하다고 명시했다.
- 측정하지 않은 FPS·동시 Agent 성능 수치는 넣지 않았다.
- 모든 슬라이드의 발표자 노트에 근거가 된 로컬 기획 문서·작업 기록·소스 파일 경로를 기록했다.

## 검증 결과

- 도형 겹침, 한글 잘림, 화살표 방향을 수정한 뒤 최종 출력했다.
