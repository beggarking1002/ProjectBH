# 2026-08-23 - Mixamo 클래스 에셋 파이프라인 확정

## 목적

공용 Polyart 에셋으로 전투를 검증한 뒤, Mixamo 캐릭터와 애니메이션으로 네 클래스의 외형을 분리하는 파이프라인을 정한다.

## Codex 변경 사항

- Polyart 가죽 갑옷 모험가를 초기 전투 수직 슬라이스의 공용 베이스로 유지했다.
- 탱커, 전사, 도적, 마법사에 서로 다른 Mixamo 캐릭터를 도입하는 방향을 반영했다.
- 하나의 기준 Mixamo 스켈레톤, 공통 애니메이션 블루프린트 구조, 공통 무기 소켓을 유지하는 기술 규칙을 작성했다.
- 캐릭터는 `With Skin`, 애니메이션은 `Without Skin`, 이동은 `In Place`를 우선 사용하는 임포트 기준을 정했다.

## 사용자 에디터 작업

1. Mixamo에서 첫 기준 캐릭터와 기본 애니메이션을 내려받는다.
2. 첫 캐릭터를 임포트해 `SKEL_BH_Mixamo` 기준 스켈레톤을 만든다.
3. 두 번째 후보 캐릭터 하나를 같은 스켈레톤에 연결해 임포트할 수 있는지 검증한다.
4. Idle, Run In Place, 기본 검 공격, Hit React, Death를 기준 스켈레톤에서 재생해 본다.

## 검증

- Adobe 공식 FAQ는 Mixamo 캐릭터와 애니메이션의 비디오 게임 포함 상업적 사용을 로열티 없이 허용한다고 안내한다.
- Mixamo 자동 리깅 및 애니메이션 라이브러리는 이족 보행 휴머노이드용이다.
