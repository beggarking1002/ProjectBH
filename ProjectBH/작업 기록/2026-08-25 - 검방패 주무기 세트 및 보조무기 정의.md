# 2026-08-25 - 검방패 주무기 세트 및 보조무기 정의

## 목적

Greystone 초기 구현에서 검+방패와 총기류의 장비 구분을 확정해, 장비 코드와 에셋 검증의 기준을 명확히 한다.

## Codex 변경 사항

- 검+방패를 하나의 `주무기 세트`로 정의했다. 방패는 독립 장비 슬롯이나 독립 전환 대상이 아니다.
- 보조무기는 총기류로 정의하고, 주무기 세트와 별도의 장비 모드로 전환하도록 정리했다.
- 장비 구조 계획을 `PrimaryMeleeSet`과 `SecondaryRanged`의 서버 권한·복제 상태 기준으로 수정했다.
- 일체형 검+방패 에셋에는 외부 검을 Spawn하지 않으며, 총기 전환 때만 주무기 형상을 숨기고 총기를 장착한다는 기준을 반영했다.

## 사용자 에디터 작업

첫 단계는 Greystone 에셋 샌드박스다. 사용자는 Fab에서 Greystone을 추가한 뒤 검+방패가 본체 메시의 일체형인지, 방패만 분리 메시인지와 실제 장착·숨김 본을 확인한다.

## 검증

- 이번 작업은 장비 기획 문서와 작업 순서만 변경했다. C++ 코드 및 Unreal 에셋은 변경하지 않았으므로 빌드는 실행하지 않았다.
- 기존 일체형 무기 숨김 원칙과 모순 없이, 총기 전환 시에만 `Hide Bone by Name`을 사용하도록 범위를 명확히 했다.
