# 2026-08-20 - 템플릿 예제 정리 범위 검토

## 목적

새로운 2인 코옵 전투 수직 슬라이스를 시작하기 전, Third Person 템플릿과 Variant 예제의 삭제 가능 범위 및 의존성을 확인한다.

## Codex 변경 사항

- 옵시디언 볼트의 프로젝트 개요, 개발 로드맵 및 기존 작업 기록을 검토했다.
- `Variant_Combat`, `Variant_Platforming`, `Variant_SideScrolling`의 C++ 및 콘텐츠가 독립적인 템플릿 예제임을 확인했다.
- `ProjectBH.Build.cs`가 Variant별 공개 인클루드 경로를 등록하고 있음을 확인했다.
- 기본 게임 맵은 `FeatureDevMap`이며, 전역 기본 게임 모드는 `BP_ThirdPersonGameMode`임을 확인했다.
- `BP_ThirdPersonCharacter`가 `AProjectBHCharacter`를 부모로 사용하므로, `ProjectBHCharacter`와 `ProjectBHGameMode`를 단독으로 먼저 삭제하면 블루프린트 또는 설정 참조가 깨짐을 확인했다.

## 사용자 에디터 작업

삭제를 실행하기 전, 새 전투 테스트 맵과 새 게임 모드/플레이어 캐릭터 블루프린트를 만들고 Project Settings의 기본 맵 및 게임 모드를 새 자산으로 지정해야 한다.

## 검증

- 텍스트 설정, C++ 참조 및 콘텐츠 패키지 내 클래스 참조를 검사했다.
- Variant 콘텐츠는 각 Variant의 블루프린트·맵·외부 액터 패키지 내부에서만 참조된다.
