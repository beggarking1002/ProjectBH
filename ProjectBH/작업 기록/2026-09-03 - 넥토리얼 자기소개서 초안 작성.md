# 넥토리얼 자기소개서 초안 작성

## 이해한 요청

Project BH와 Project OCH에서 실제로 구현하고 기록한 경험을 근거로, 2026 넥토리얼 게임 프로그래머 지원서의 자기소개 문항 4개에 대한 수정 가능한 초안을 작성한다.

## 작업 내용

- 2026 넥토리얼 공식 안내에서 게임 프로그래머 업무, 요구 역량, AI 활용 역량평가 기준을 확인했다.
- Project OCH의 C++ IOCP 서버, 방 단위 JobQueue, Protocol Buffers 연동, 서버 권한 전투 구조를 역량 근거로 정리했다.
- Project BH의 다수 적 포위 AI와 `CoreEscape` 전역 승격 교착 해결을 대표 문제 해결 사례로 선정했다.
- 문서상 확인되지 않는 팀원과의 갈등 경험은 만들지 않고, 현재 사실로 설명 가능한 AI 페어 프로그래밍 피드백 경험을 3번 초안으로 사용했다.
- 결과물은 [[2026 넥토리얼 자기소개서 초안]]에 저장했다.
- 초안을 처음 읽는 사람 관점으로 검토한 결과, 2번의 문제 계측과 원인 규명이 가장 강한 부분으로 확인됐다.
- 기술 약어를 일반어로 풀고, 1번을 넥토리얼 공고의 구체적 평가 범위와 연결했으며, 4번은 도구 목록보다 관측·국소화·검증 역량을 중심으로 다듬었다.
- 프로젝트 사실의 기준 문서는 Project BH 작업 기록과 Project OCH 기술 포트폴리오로 유지하고, 자기소개서에는 필요한 근거만 요약했다. 별도 SSOT 통합은 하지 않았다.

## 남은 확인

- 각 문항의 실제 입력창 글자 수 계산 방식 확인
- 3번 문항을 대체할 사람 중심 협업 사례 유무 확인
- `CoreEscape` 교착 수정 전후를 보여 주는 PIE 영상 또는 수치 확보
