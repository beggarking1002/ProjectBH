# 2026-08-25 - Mixamo 회피 및 방어 애니메이션 다운로드 절차

## 목적

Mixamo에서 찾은 회피·방어 후보를 Greystone에 리타기팅하기 위한 다운로드·임포트 규칙을 확정했다.

## 결정

- Mixamo 기준 캐릭터 하나를 Source Skeleton으로 한 번만 With Skin으로 받는다.
- 회피·방어 등 개별 클립은 동일 캐릭터 기준으로 Without Skin, FBX Binary, 가능하면 60 FPS, Keyframe Reduction None으로 받는다.
- 회피는 In Place + Loop 해제, Guard는 In Place + Loop 활성화를 기본으로 한다.
- 첫 도입 범위는 Roll/Dodge 1개, Guard Loop 1개, 필요 시 Hit/Death 한 개씩이다.
- UE 임포트 시 첫 With Skin FBX는 무기 없는 X Bot/Y Bot Idle로 새 Source Skeleton만 만든다. 실제 Guard/Roll 클립은 같은 Source 캐릭터에서 Without Skin으로 다시 받아 Animation Only로 임포트한다.
- Without Skin 애니메이션은 `SKEL_Mixamo_Source`를 선택한 Animation Only 임포트로 받고, 60 FPS 원본은 UE 기본 30 FPS 재샘플을 끄고 Custom Sample Rate 60을 사용한다.
- UE 5.7 Interchange 화면에서는 첫 With Skin FBX에 `Import Only Animations` 해제, `Skeleton=None`, `Import Meshes in Bone Hierarchy` 해제, `Use T0 As Ref Pose` 해제, `Add Curve Metadata to Skeleton` 해제를 적용한다. 하단 `Skeletal Meshes > Import Skeletal Meshes`는 반드시 활성화한다.
- 아무 에셋도 생성되지 않은 경우에는 With Skin 파일 여부와 Interchange의 Skeletal Mesh 생성 옵션을 확인하고, FBX 인식 오류일 때만 세션 단위 Legacy FBX Importer 전환을 사용한다.
- Greystone을 최종 Target Skeleton, Mixamo 캐릭터를 Source Skeleton으로 명확히 분리한 전체 워크플로우를 추가했다. Without Skin FBX는 Greystone에 직접 임포트하지 않고 Mixamo Source Skeleton에 Animation Only로 임포트한 뒤 IK Retargeter로 Greystone용 Sequence를 복제한다.
- 무기·소품이 포함된 첫 With Skin FBX가 뒤틀린 사례를 반영해, X Bot/Y Bot의 무기 없는 Idle을 Source Skeleton 생성용으로만 쓰도록 절차를 정정했다. 실제 `sword_and_shield_block_idle`은 동일 Source 캐릭터에서 Without Skin으로 받는다.

## 사용자 작업

- Mixamo에서 Source 캐릭터와 후보 클립을 다운로드하고, Raw Source/Animations 경로에 임포트한다.
- Source IK Rig에서 Greystone IK Rig로 회피 1개와 Guard 1개만 먼저 리타기팅한다.
