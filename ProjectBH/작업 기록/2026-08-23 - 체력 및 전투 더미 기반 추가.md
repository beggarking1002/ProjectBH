# 2026-08-23 - 체력 및 전투 더미 기반 추가

## 목표

- 영웅과 적이 공통으로 사용할 체력 속성을 GAS 기반으로 추가한다.
- 리슨 서버 환경에서 체력 값이 모든 클라이언트에 복제될 수 있도록 한다.
- 이후 공격과 피해 판정에 사용할 정지형 전투 더미 C++ 클래스를 만든다.

## 구현

- `UBHAttributeSet`에 `Health`, `MaxHealth`를 추가했다.
  - 기본값은 각각 `100`이다.
  - 두 속성은 GAS 리플리케이션 알림을 사용해 모든 클라이언트에 동기화된다.
  - `Health`는 항상 `0 ~ MaxHealth` 범위로 제한된다.
- `ABHCombatDummy`를 `ABHBaseCharacter` 기반으로 추가했다.
  - 이동과 AI 자동 빙의가 비활성화된 정지형 캐릭터다.
  - 컨트롤러가 없는 더미도 GAS ActorInfo를 초기화한다.

## 에디터에서 할 일

1. C++ 컴파일 후 콘텐츠 브라우저에서 `ABHCombatDummy`를 부모로 `BP_CombatDummy`를 만든다.
2. `BP_CombatDummy`의 Mesh에 확인용 스켈레탈 메시를 지정하고 테스트 맵에 하나 배치한다.
3. 다음 단계에서 도끼 공격의 서버 판정과 Gameplay Effect를 연결해 이 더미의 `Health`를 깎는다.

## 멀티플레이 기준

- 체력 변경은 서버 권한에서만 발생시킨다.
- 서버가 변경한 `Health`와 `MaxHealth`는 GAS 속성 복제를 통해 호스트와 클라이언트에 전달된다.
