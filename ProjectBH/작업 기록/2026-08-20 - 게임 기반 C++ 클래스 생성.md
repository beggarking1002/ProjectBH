# 2026-08-20 - 게임 기반 C++ 클래스 생성

## 목적

템플릿 게임 모드 구조를 대체할 ProjectBH 전용 C++ 게임 기반 클래스를 만든다.

## Codex 변경 사항

- `ABHGameMode`를 추가하고 기본 폰을 `ABHHeroCharacter`, 플레이어 컨트롤러를 `ABHHeroController`로 지정했다.
- `ABHHeroController`를 추가했다.
- 공통 캐릭터 기반인 추상 `ABHBaseCharacter`를 추가하고, 이동 복제를 활성화했다.
- `ABHHeroCharacter`를 `ABHBaseCharacter`의 파생 클래스로 추가했다.
- `ABHHeroCharacter`에 `CameraBoom`과 그 끝에 부착되는 `FollowCamera`를 추가했다. 카메라는 컨트롤러 회전을 따르고, 캐릭터는 이동 방향을 향한다.
- 히어로의 기본 사양으로 캡슐 반지름/반높이 `42/96`, 카메라 붐 길이 `200`, 소켓 오프셋 `(0, 55, 65)`, 최대 걷기 속도 `400`, 걷기 감속 `2000`을 설정했다.
- 전역 기본 GameMode를 `/Script/ProjectBH.BHGameMode`로 변경했다.
- `Source/ProjectBH/Variant_Combat`, `Variant_Platforming`, `Variant_SideScrolling`을 삭제하고 `ProjectBH.Build.cs`의 Variant 공개 인클루드 경로를 제거했다.

## 사용자 에디터 작업

- Unreal Editor를 재시작하거나 C++ 모듈을 다시 컴파일한 뒤 새 클래스를 인식시킨다.
- `ABHHeroCharacter` 기반 블루프린트를 만든 뒤 메시, 애니메이션 블루프린트, 입력을 연결한다.
- 새 전투 테스트 맵을 만들면 World Settings의 GameMode Override가 비어 있는지 확인해 전역 `BHGameMode`를 사용하게 한다.

## 검증

- Variant 소스 삭제 뒤에도 남아 있던 `Intermediate/ProjectFiles`의 Variant 컴파일 항목을 Unreal Build Tool `-ProjectFiles` 실행으로 재생성했다. 재생성 결과는 성공했으며, 생성된 프로젝트 파일에 Variant 참조가 남아 있지 않음을 확인했다.
- 에디터 종료 후 생성물인 `Binaries`, `Intermediate`를 정리하고 프로젝트 파일을 다시 생성했다.
- `ProjectBHEditor Win64 Development` 전체 빌드는 102개 작업을 모두 통과했고 `Result: Succeeded`로 완료됐다.
- 카메라 컴포넌트 추가는 `UCLASS` 헤더 변경을 포함하므로 Unreal Editor 종료 후 전체 빌드로 재검증해야 한다.

## Rider 빌드 오류 수정

- `UnrealBuildTool failed with exit code 0xe0434352`의 실제 원인은 Git이 한글 파일명을 이스케이프해 출력한 경로를 Unreal Build Tool이 잘못 해석한 것이었다.
- 이 저장소에만 적용되도록 Git 설정 `core.quotepath`를 `false`로 변경했다. 따라서 작업 기록 등 한글 경로가 있어도 Rider와 Unreal Build Tool이 파일 작업 집합을 정상 처리한다.
