# 2026-08-23 - 원본 프로젝트 엔진 버전 미설치 대응 추가

## 목적

다른 프로젝트의 요구 Unreal Engine 버전이 설치되어 있지 않아 에셋 Migrate를 실행할 수 없는 상황의 대응 절차를 추가한다.

## Codex 변경 사항

- `.uproject`의 `EngineAssociation` 확인, 원본 엔진 설치, `Open a Copy` 사용 절차를 개발 가이드에 추가했다.
- 원본보다 낮은 엔진 버전으로는 열 수 없고, 플러그인·C++ 의존성이 있으면 별도 대응이 필요함을 정리했다.

## 사용자 에디터 작업

1. 원본 프로젝트 `.uproject`의 `EngineAssociation` 값을 확인한다.
2. Epic Games Launcher에서 같은 버전의 엔진을 설치한다.
3. 원본을 직접 변환하지 않고 복사본으로 열어 Migrate를 실행한다.

## 검증

- Migrate 기능은 원본 Unreal Editor 프로젝트에서 실행해야 한다는 전제에 따라 절차를 구성했다.

## 관련 파일
