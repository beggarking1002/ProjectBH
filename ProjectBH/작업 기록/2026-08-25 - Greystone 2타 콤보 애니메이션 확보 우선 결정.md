# 2026-08-25 - Greystone 2타 콤보 애니메이션 확보 우선 결정

## 목적

Greystone 검+방패 전투 수직 슬라이스에서 DataTable과 서버 판정 구현보다 먼저, 실제 평타 2연속 콤보 애니메이션을 확보·선정한다.

## Codex 변경 사항

- 전투 수직 슬라이스 체크리스트에 `현재 다음 작업: 2타 콤보 애니메이션 확보` 단계를 추가했다.
- 원본 Greystone Animation Sequence를 먼저 미리 보고, 검+방패 유지, Root Motion 이동량, 1타→2타 연결, 타격 구간의 명확성을 기준으로 선정하도록 정리했다.
- 선정한 애니메이션은 `Content/ProjectBH/Characters/Greystone/Animations/Combat/`에 ProjectBH 전용 복제본으로 보관하고, 원본 Animation Sequence·Skeleton·AnimBP는 수정하지 않는 기준을 기록했다.
- 현재 C++의 `BH Melee Trace`는 공격 판정 방식과 Notify 명칭을 확정하기 전 후보 상태로 유지한다.
- `/Game/Assets/Animation`의 `AM_Knight`에 `Attack_A/Recovery_A`, `Attack_B/Recovery_B`, `Attack_C/Recovery_C` 구성이 준비된 것을 기록했다.
- 추가 입력이 없으면 현재 공격의 Recovery까지 재생 후 종료하고, 입력이 있으면 A→B→C로 연결하며 Recovery_C에서 끝나는 규칙을 기록했다.

## 사용자 에디터 작업

1. `AM_Knight`의 Attack/Recovery 구간이 Greystone 원본 메시에서 정상적으로 재생되는지 확인한다.
2. 각 Attack 구간의 실제 타격 순간을 확인해, 추후 `ANS_MeleeHitWindow` 위치를 기록한다.
3. 현재 수직 슬라이스에 3타 `Attack_C`를 포함할지 결정한다.

## 검증

- 사용자가 `/Game/Assets/Animation/AM_Knight`의 실제 콤보 구성을 확인해 공유했다. Greystone 원본 메시와의 재생·손 위치 검증은 Unreal Editor에서 이어서 수행해야 한다.
- C++ 코드, DataTable, Montage, Socket은 이번 작업에서 변경하지 않았다.
