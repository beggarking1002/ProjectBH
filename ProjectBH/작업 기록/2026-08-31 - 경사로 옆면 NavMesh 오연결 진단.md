# 경사로 옆면 NavMesh 오연결 진단

## 현상

- 다른 테스트 맵에서 Player가 경사로 위에 있을 때 Enemy들이 실제 입구로 우회하지 않고 경사로 옆면에 모여 정지했다.
- 첨부 화면의 NavMesh 디버그는 `AgentMaxStepHeight 35 / 200 / 35 (Low/Default/High)`를 표시했다.

## 원인

- ProjectBH의 `Config/DefaultEngine.ini`에는 Low·Default·High가 모두 `35 cm`로 저장되어 있다.
- 테스트 레벨의 `RecastNavMesh-Default` 인스턴스 또는 저장된 Navigation Data에서 Default 해상도의 Step Height가 `200 cm`로 Override된 상태로 판단된다.
- 이 값에서는 경사로 옆면의 큰 높이 차도 걸을 수 있는 단차로 처리될 수 있다. Pathfinding은 잘못 생성된 짧은 연결을 정상 경로로 선택하므로 Enemy가 실제 경사로 입구 대신 옆면으로 이동한다.
- 슬롯 목적지나 Detour Crowd 회피를 먼저 수정할 문제가 아니다. 잘못된 NavMesh 연결을 유지한 채 AI 코드로 우회점을 추가하면 특정 맵에 종속된 예외가 된다.

## 에디터 수정 절차

1. PIE를 종료한다.
2. World Outliner에서 `RecastNavMesh-Default`를 선택한다.
3. Details의 `NavMesh Resolution Params > Default > Agent Max Step Height`를 `35 cm`로 변경하거나 Override를 Reset한다.
4. `Build > Build Paths`를 실행한다.
5. `P`를 눌러 `35 / 35 / 35`인지 확인한다.
6. 경사로 옆면에는 NavMesh 연결이 없고 실제 입구의 경사면은 아래 바닥과 연속인지 확인한다.

## 입구 NavMesh가 끊길 경우

- Step Height를 다시 키우지 않는다.
- 경사로 Static Mesh의 단순 Collision, 입구 턱, 바닥과 경사면 사이의 틈을 먼저 수정한다.
- Collision을 수정할 수 없는 작은 단절이면 실제 입구에만 `Nav Link Proxy`를 배치한다.
- Nav Link 양 끝은 Enemy Capsule이 설 수 있는 녹색 NavMesh 위에 두며, 경사로 옆면을 가로지르지 않게 한다.

## 후속 확인: 경사로 내부 NavMesh 구멍

- 후속 화면에서는 `AgentMaxStepHeight 35 / 60 / 35`에서도 경사로 장식 판 주변에 NavMesh 구멍이 남았다.
- Step Height를 높이면 이 구멍은 채워지지만, 같은 값이 경사로 옆 절벽도 이동 가능한 단차로 연결한다. 따라서 전역 Step Height 하나로 두 현상을 함께 해결할 수 없다.
- 권장 해결은 `전역 35 cm 유지 + 경사로 보행면 단순 Collision`이다.

### 권장 작업

1. 장식 판이 별도 Mesh면 `Can Ever Affect Navigation`을 끈다.
2. 경사로의 실제 걷는 면에 얇은 Blocking Volume 또는 숨겨진 단순 Collision Mesh를 배치한다.
3. 곡선 경사로라면 여러 개의 짧은 Volume을 이어 붙여 표면을 따른다.
4. 보조 Collision이 옆 절벽이나 아래 바닥과 접촉하지 않게 한다.
5. Default Step Height를 `35 cm`로 되돌리고 Navigation을 재빌드한다.

### 대안 우선순위

1. 단순 Collision으로 연속 NavMesh 생성: 넓은 몬스터 군중에 가장 적합
2. 폭을 가진 `Nav Link Proxy > Segment Links`: Collision 수정이 어려울 때
3. Point Link 여러 개: 빠른 임시 검증용
4. 국소 High Resolution + 높은 Step Height: 타일 전체의 옆면 오연결 위험 때문에 비권장

## 합격 조건

- Default `Agent Max Step Height`가 `35 cm`다.
- Enemy의 표시 경로가 경사로 옆면이 아니라 실제 입구를 지난다.
- 여러 Enemy가 동시에 접근해도 옆면에 새 교착 군집이 생기지 않는다.
- 평지와 기존 Corridor 테스트의 이동 결과가 유지된다.
