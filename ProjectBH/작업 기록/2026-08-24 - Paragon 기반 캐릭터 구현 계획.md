# 2026-08-24 - Paragon 기반 캐릭터 구현 계획

## 목적

Paragon 무료 에셋을 ProjectBH의 네 클래스 외형과 애니메이션 출발점으로 사용하기 위한 구현 순서를 설계한다.

## Codex 변경 사항

- Paragon 에셋과 ProjectBH 고유 시스템의 책임을 분리했다.
- 전사 Greystone 하나의 에셋 샌드박스부터 시작하는 네 단계 도입 계획을 작성했다.
- 영웅별 Skeleton 차이를 공통 C++ 전투 시스템과 캐릭터별 데이터·블루프린트로 처리하는 구조를 정의했다.
- 외부 무기와 보조장비, 특히 석궁을 캐릭터와 분리된 ProjectBH 장비로 확장하는 계획을 작성했다.

## 사용자 에디터 작업

- Fab에서 Paragon: Greystone 팩 하나를 ProjectBH에 추가한다.
- 메시, Skeleton, AnimBP, 양손검 공격·피격·사망, 무기 소켓을 테스트한다.

## 검증
