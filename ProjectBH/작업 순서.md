# Greystone 검+방패 구현 작업 순서

> 기준일: 2026-08-25. 첫 플레이어 캐릭터는 Greystone이며, 검+방패 근접 전투를 먼저 검증한다.

## 0. 에셋 샌드박스 — 사용자: Unreal Editor

1. Greystone 에셋은 `/Game/ParagonGreystone/Characters/Heroes/Greystone/Meshes`에서 확인한다. 검과 방패는 본체 Skeletal Mesh에 일체형이며, Skeleton 본 이름은 각각 `sword`, `shield`다.
2. Skeletal Mesh, Skeleton, Physics Asset, AnimBP를 열어 Idle, 이동, 검+방패 공격, 가드, 피격, 사망을 재생한다.
3. Skeleton Tree에서 다음을 기록한다.
   - 검과 방패 형상을 실제로 움직이는 본 또는 메시 구조
   - 오른손·왼손 장착 본과 사용할 Mesh Socket 이름
   - `sword` 본의 칼날 끝에 만들 `SwordTraceTip` Mesh Socket 위치
   - 원거리 전환 시 숨길 근접 무기 본 후보
4. `BP_PBH_Greystone_VisualTest`에서 `Hide Bone by Name`을 PIE로 시험한다. 근접 무기만 숨겨지고 손·팔이 유지되는지, 공격 중 다시 보이지 않는지 확인한다.

완료 기준: 검+방패 시각 에셋이 정상 재생되고, `SwordTraceTip`이 칼날 끝을 정상적으로 따르며, 총기 전환에 사용할 실제 본·소켓 이름과 본 숨김 가능 여부가 기록된다.

## 1. 장비·전투 기반 정리 — Codex

에셋 샌드박스 결과를 받은 뒤 현재의 단일 `ABHWeapon` 구조를 다음 기준으로 확장한다.

- 일체형 검과 방패는 별도 장착 액터를 생성하지 않는 `내장 주무기 세트`로 취급한다. 현재 `StartingWeaponClass`에 외부 검을 지정하면 이중으로 보이므로 사용하지 않는다.
- 주무기 슬롯은 검+방패 세트 하나이며, 보조무기 슬롯은 총기류 하나다. 방패는 독립 장비 슬롯 또는 독립 전환 대상이 아니다. 에셋 구조상 방패가 분리 메시라면 주무기 세트를 표현하는 전용 장착 구성에 포함한다.
- 서버가 현재 장비 모드(`PrimaryMeleeSet` / `SecondaryRanged`)를 복제한다. 모든 클라이언트는 이 상태에 맞춰 주무기 세트 본 숨김과 총기 장착을 동일하게 표현한다.
- 장비 슬롯, 장착 본/소켓, 숨김 본 목록, 공격 Montage, 타격 소켓, 피해 GE는 Greystone 전용 설정으로 시작하되 이후 데이터 에셋으로 분리할 수 있게 구성한다.
- `InputTag.BasicAttack`은 `InputTag.Attack.Light`로 정리하고, 공격 중복을 막는 `State.Attacking` 및 사망 상태 `State.Dead`를 추가한다. 블루프린트 입력 데이터 에셋도 같은 태그로 갱신한다.

완료 기준: 외부 도끼를 전제로 한 단일 장착 구조를 제거하고, 검+방패 주무기 세트 상태와 보조 총기 상태를 서버 권한으로 전환할 수 있다.

## 2. Greystone 근접 기본 공격 — Codex + 사용자

1. 사용자는 Greystone 검 공격 애니메이션을 ProjectBH 전용 Montage로 복제하고, 공격 활성 구간에 전용 `Anim Notify State`를 배치한다.
2. Codex는 즉시성 중심 구형 Sweep을 검 궤적 추적으로 교체한다.
   - 검의 시작·끝 소켓 위치를 공격 활성 구간 동안 매 프레임 이전 위치와 현재 위치 사이에서 Sweep한다.
   - 서버만 Trace와 Gameplay Effect 적용을 수행한다.
   - 한 공격 활성 구간에 같은 대상은 한 번만 피해를 받게 한다.
3. 공격 시작·종료 및 현재 전투 행동을 복제해 호스트와 클라이언트가 동일한 Montage·피격 결과를 보게 한다.

완료 기준: 호스트와 클라이언트 모두 Greystone의 검 공격을 보고, 애니메이션 활성 구간에만 더미 체력이 한 번 감소한다.

## 3. 방패와 가드 — Codex + 사용자

- 사용자는 방패 메시가 내장인지 분리인지에 맞춰, 검+방패 주무기 세트의 왼손 장착 위치와 가드 Montage를 준비한다.
- Codex는 가드 입력, 서버 권한 가드 상태, 이동 제한, 피격 피해 감소/무효의 최소 규칙을 추가한다.
- 가드 중에는 근접 무기 상태를 유지하며, 보조 총기 상태에서는 가드를 허용하지 않는다.

완료 기준: 두 클라이언트에서 가드 자세와 실제 피해 감소 결과가 일치한다.

## 4. 보조 총기 전환 — Codex + 사용자

1. 사용자는 검을 숨길 실제 본과 총기 장착 소켓을 확정하고, 총기 Idle/발사 Montage를 준비한다.
2. Codex는 서버 RPC로 장비 모드를 바꾸고, 복제된 상태의 OnRep에서 근접 무기 본 숨김·총기 액터 부착을 적용한다.
3. 총기 공격은 근접 타격과 별도 입력·발사 규칙을 사용한다. 첫 단계에서는 투사체 또는 Hitscan 중 하나를 선택해 서버만 명중·피해를 확정한다.
4. 근접 무기 형상이 숨겨지지 않는 에셋은 총기 보조무기 대상에서 제외하고, [[Paragon 일체형 무기 제거 및 교체 절차]]의 다음 단계를 별도 검토한다.

완료 기준: 호스트와 클라이언트 모두 전환 시 검이 보이지 않고 총기가 손에 붙으며, 발사와 피해 결과가 일치한다.

## 5. 마무리 검증

- Listen Server 1명 + Client 1명 PIE에서 장착, 공격, 가드, 무기 전환, 피해, 사망을 순서대로 검증한다.
- 체력 0에서 `State.Dead`를 복제하고 이동·입력·공격을 차단한다. 사망 Montage와 간단한 리스폰 또는 더미 제거를 연결한다.
- 전투 수직 슬라이스가 안정된 후에만 2타 콤보, 강공격, 퍼펙트 가드, 캐릭터 데이터 에셋 일반화를 진행한다.

## 현재 코드에서 변경이 필요한 항목

| 우선순위 | 현재 상태 | 필요한 변경 |
| --- | --- | --- |
| 필수 | `ABHHeroCharacter`가 `StartingWeaponClass`와 `EquippedWeapon` 하나만 관리 | 내장 검+방패 주무기 세트와 보조 총기 슬롯을 구분하고, 서버 권한 장비 모드를 복제 |
| 필수 | 외부 도끼를 `Weapon_R` 소켓에 Spawn | Greystone의 일체형 검+방패 세트에는 Spawn하지 않도록 하고, 보조 총기만 해당 슬롯에 Spawn·부착 |
| 필수 | `PerformBasicAttackHit`이 캐릭터 앞의 단일 구형 Sweep | 검 메시/본의 시작·끝 소켓 기반 연속 Sweep과 공격별 중복 피격 방지로 교체 |
| 필수 | 단일 `UAnimNotify`가 순간 타격을 호출 | 검이 유효한 구간을 표현하는 `UAnimNotifyState`로 전환 |
| 필수 | `InputTag.BasicAttack`, 단순 쿨다운만 존재 | `InputTag.Attack.Light`, `State.Attacking`, `State.Dead` 및 서버 권한 행동 상태 추가 |
| 다음 단계 | 체력이 0이어도 캐릭터가 계속 행동 | Health 0 감지, 사망 상태 복제, 이동·입력·공격 차단, 사망 연출 추가 |
| 다음 단계 | `ABHWeapon`은 Static Mesh 하나만 보유 | 총기가 Skeletal Mesh 또는 별도 연출 컴포넌트를 요구하는지 샌드박스 결과를 보고 범용 장비 액터로 확장 |
