# 언리얼 에셋 마이그레이션 절차

다른 Unreal Engine 프로젝트의 에셋을 ProjectBH로 가져올 때는 파일 탐색기 복사가 아니라 Unreal Editor의 `Migrate` 기능을 사용한다. 이 기능은 선택한 에셋의 머티리얼, 텍스처, 스켈레톤, 애니메이션 등 참조 의존성을 함께 복사한다.

## 이관 전 확인

- 원본과 대상 프로젝트의 엔진 버전을 확인한다. 대상이 원본보다 낮은 엔진 버전이면 호환 문제가 발생할 수 있다.
- 대상 프로젝트에서 같은 경로·이름의 에셋이 이미 있는지 확인한다. 덮어쓰기는 기존 참조를 깨뜨릴 수 있다.
- 캐릭터는 스켈레탈 메시만 선택하지 말고, 캐릭터 블루프린트 또는 에셋 팩의 최상위 폴더를 기준으로 선택한다.

## 원본 프로젝트를 열 수 없는 경우

`Migrate`는 원본 프로젝트를 Unreal Editor에서 열어야 사용할 수 있다. 원본 프로젝트가 요구하는 엔진 버전이 설치되어 있지 않다면 다음 순서로 처리한다.

1. 원본 프로젝트의 `.uproject` 파일을 메모장으로 열어 `EngineAssociation` 값을 확인한다.
2. Epic Games Launcher의 `Unreal Engine → Library → Engine Versions`에서 해당 버전을 설치한다.
3. 원본 프로젝트를 처음 열 때 버전 변환을 묻는 경우, 원본을 덮어쓰지 말고 `Open a Copy`를 선택한다.
4. 복사본이 정상적으로 열리면 그 복사본에서 `Migrate`를 실행한다.

### 예외 처리

- 원본이 현재 ProjectBH보다 **더 새로운 엔진 버전**이면, ProjectBH보다 같거나 높은 엔진을 설치해야 한다. 낮은 버전 엔진에서는 열 수 없다.
- 원본이 더 오래된 엔진 버전이면, 현재 엔진에서 복사본 변환을 시도할 수 있다. 다만 블루프린트, 플러그인, 물리·애니메이션 설정의 변환 오류 가능성이 있으므로 원본은 보존한다.
- 프로젝트가 특정 플러그인 또는 C++ 코드에 의존해 열리지 않으면, 해당 플러그인을 설치·활성화하거나 에셋 원본 파일(FBX, 텍스처 등)을 별도로 받아 ProjectBH에 직접 임포트한다.
- 원본 프로젝트의 `.uasset` 파일만 탐색기에서 복사하는 방법은 의존성이 누락되기 쉬우므로 마지막 수단으로도 권장하지 않는다.

## 에디터 작업 순서

1. **원본 프로젝트**를 Unreal Editor로 연다.
2. Content Browser에서 옮길 에셋 또는 최상위 에셋 폴더를 선택한다.
3. 우클릭 후 `Asset Actions → Migrate`를 선택한다.
4. `Asset Report`에서 포함된 의존성 목록을 확인한다. 캐릭터라면 스켈레탈 메시, Skeleton, Physics Asset, 머티리얼, 텍스처, 애니메이션, Animation Blueprint, Montage가 포함되는지 본다.
5. 특별한 이유가 없으면 의존성 체크를 해제하지 않고 `OK`를 누른다.
6. 대상 폴더로 **`C:\UE5\ProjectBH\Content`**를 선택한다. 프로젝트 루트나 `Content` 내부의 하위 폴더를 목적지로 선택하지 않는다.
7. 같은 이름의 에셋을 덮어쓸지 묻는 창이 나오면, 의도적으로 교체하는 경우가 아니라면 `No` 또는 `No All`을 선택하고 충돌 원인을 확인한다.
8. ProjectBH 에디터를 열거나 포커스로 전환해 가져온 에셋을 확인한다.

## ProjectBH에서의 정리 및 검증

1. 가져온 폴더를 Content Browser에서 `Content/ThirdParty/<출처명>/`으로 옮긴다. 파일 탐색기에서 `.uasset` 파일을 직접 옮기지 않는다.
2. 에셋 폴더를 우클릭해 `Fix Up Redirectors in Folder`를 실행한다.
3. 캐릭터라면 스켈레탈 메시, 머티리얼, Animation Blueprint를 각각 열어 오류가 없는지 확인한다.
4. 임시 테스트 블루프린트에 메시와 Animation Blueprint를 연결해 Idle, 이동, 공격, 피격, 사망을 재생한다.
5. 원본 에셋은 수정하지 않는다. ProjectBH 고유의 머티리얼 인스턴스, 블루프린트, 리타기팅 결과는 `Content/ProjectBH/`에 만든다.

## Mixamo 캐릭터에 적용

Mixamo에서 받은 FBX는 먼저 `Content/ThirdParty/Mixamo/Raw/`에 임포트한다. 기준 스켈레톤과 리타기팅 결과, 클래스 블루프린트는 `Content/ProjectBH/Characters/`에 만든다. Mixamo에서 직접 받은 FBX는 다른 Unreal 프로젝트에서 Migrate할 필요 없이 대상 프로젝트에 직접 임포트한다.

## 주의사항

- `.uasset`만 직접 복사하면 참조된 텍스처·머티리얼·Skeleton 등이 빠질 수 있다.
- 한 에셋만 선택해 필요한 Animation Blueprint나 무기·이펙트가 빠졌다면, 원본에서 상위 폴더 또는 캐릭터 Blueprint를 기준으로 다시 Migrate한다.
- 가져온 뒤 경로를 바꿀 때는 Content Browser에서 이동해야 참조가 자동으로 갱신된다.
